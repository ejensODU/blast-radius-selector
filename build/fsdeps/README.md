# fsdeps — measured file-system dependencies of the sqlglot test suite

Build the image once with `docker build -t rwx-fstrace:1 img` (rwx-label:1 + strace), then run `python3 drive.py --jobs 4 [--force] [--only KEY...]`: for every test file in `../../kit/sample/tests.json` (plus `tests/test_docs.py` and `tests/test_integration_loader.py`, which exist in the tree but collect 0 tests under pytest) and once for the whole suite (`whole-suite`, `python -m pytest` with no argument), it starts a fresh `rwx-fstrace:1` container (`--network none`, 2 CPUs, 4 GB, `SYS_PTRACE`, seccomp unconfined) that runs `inrun.sh`: copy `/opt/sqlglot-pristine` to `/work/tree` exactly like `farm/lab/runner.py`, then `strace -f -y -e trace=%file,getdents64,execve,chdir,fchdir python -m pytest <file> -p no:cacheprovider` with cwd `/work/tree`, `PYTHONPATH=/work/tree:/fs/hook` (so `hook/sitecustomize.py` loads in every Python process: audit hooks for listdir/scandir/glob/walk, non-import `open` of repo files, `subprocess.Popen`, plus a last-in-`sys.meta_path` finder that logs every module name nobody could find). Raw outputs go to `raw/<key>.{strace,jsonl,log,rc}` (cached; `--force` reruns). `python3 parse.py` folds them into `fsdeps.json` (repo-relative paths; `__pycache__`, `.pyc`, `.pytest_cache` dropped; extra keys beyond the requested ones: `written`, `config_probes` (every access to pytest.ini/.pytest.ini/pyproject.toml/tox.ini/setup.cfg/conftest.py, in or above the repo), `py_opens_non_py` (Python-level opens of repo files by non-import code, with stack), `python_processes`, `execve`, `pytest_summary`), and `python3 report.py` prints the human summary. A full run takes about 6 minutes at 4 jobs.
